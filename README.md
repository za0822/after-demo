# AFTER — Digital Legacy Management Demo

A trilingual graduation-design prototype in Chinese, Korean and English.

Open [the demo](https://za0822.github.io/after-demo/?page=01). Language links: [中文](https://za0822.github.io/after-demo/?page=01&lang=zh) · [한국어](https://za0822.github.io/after-demo/?page=01&lang=ko) · [English](https://za0822.github.io/after-demo/?page=01&lang=en).

This repository contains the compiled static website. Demo decisions stay in the current browser's localStorage. Browsers and devices have independent state. No real accounts are connected and no real email, transfer or destruction is performed. Private demo content remains concealed until explicitly reviewed.

The server-backed TV/iPad pairing and real sharing endpoints are not hosted on GitHub Pages. Use the main demo link on phones, tablets and computers.

Font licenses are included in the assets and licenses folders. Images and simulated media are demonstration assets.
